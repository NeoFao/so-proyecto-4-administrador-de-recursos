# PARTE 1 — Evidencias Requeridas para Acreditación

## 1.1 Paquete de Evidencias por Cohorte (a conservar por la coordinación académica)

| Categoría | Evidencia específica | Vínculo con Mapa ABET/CDIO |
|---|---|---|
| Planificación curricular | Syllabus, Cronograma, Matriz Competencia→Resultado→Evidencia→Evaluación | Standard 2 (Learning Outcomes) |
| Resultados de aprendizaje | Muestra representativa de Proyectos 1–4 con sus documentos IEEE (mínimo 3 estudiantes por nivel de desempeño: excelente, competente, en desarrollo) | ABET (1), (2), (6) |
| Evaluación de competencias | Rúbricas aplicadas (analítica, ISO/IEC 25010, defensa técnica, Invenio Fest) con calificaciones registradas | ABET (1)–(6), CDIO Standard 11 |
| Comunicación técnica | Documentos IEEE completos y Portafolios Técnicos Finales (muestra representativa) | ABET (3) |
| Trabajo interdisciplinario | Evidencias de participación en Invenio Fest (pósteres, presentaciones) | ABET (5) |
| Integridad académica | Registro de aplicación de la Política de IA y resultados de Defensa Técnica Individual | ABET (4) |
| Mejora continua | Informe de cierre de curso con análisis de resultados por RAC (ver Parte 2) | CDIO Standard 11, Estrategia de Mejora Continua (Fase 4) |

## 1.2 Formato de Conservación
- Documentos digitales (PDF) organizados por cohorte/trimestre en repositorio institucional (Google Drive/SharePoint institucional, fuera del repositorio individual de GitHub del estudiante).
- Conservar evidencia muestral (no la totalidad de cada cohorte) salvo requerimiento explícito del organismo acreditador.
- Periodo mínimo de conservación recomendado: el definido por la política institucional de Universidad Invenio para procesos de acreditación (verificar con la oficina de aseguramiento de calidad institucional vigente al momento de cada ciclo de acreditación).

# PARTE 2 — Indicadores de Calidad del Curso

## 2.1 Indicadores de Resultado de Aprendizaje (por RAC)

| Indicador | Fórmula / forma de cálculo | Meta sugerida |
|---|---|---|
| % de estudiantes con desempeño "Competente" o superior en cada RAC | (Nº estudiantes con calificación ≥3 en criterios asociados al RAC / Total estudiantes) × 100 | ≥ 75% |
| Promedio de calificación en Rúbrica ISO/IEC 25010 por proyecto | Promedio simple de las 4 rúbricas ISO aplicadas | ≥ 3.0 / 4.0 |
| % de estudiantes que aprueban la Defensa Técnica en primera instancia | (Nº aprobados / Total presentados) × 100 | ≥ 80% |
| Promedio de calificación en Participación Invenio Fest | Promedio simple de la Rúbrica 4 | ≥ 3.0 / 4.0 |

## 2.2 Indicadores de Proceso del Curso

| Indicador | Forma de cálculo | Meta sugerida |
|---|---|---|
| % de avance del cronograma cumplido según lo planificado | (Nº semanas ejecutadas conforme al Plan de Clase / 11) × 100 | ≥ 90% |
| Tasa de entrega a tiempo por proyecto | (Nº entregas a tiempo / Total estudiantes) × 100, por cada uno de los 4 proyectos | ≥ 85% |
| % de estudiantes que completan el Portafolio Técnico Final | (Nº portafolios entregados / Total estudiantes) × 100 | 100% |

## 2.3 Indicadores de Satisfacción y Pertinencia

| Indicador | Instrumento | Meta sugerida |
|---|---|---|
| Percepción de utilidad del curso para la práctica dual | Encuesta de cierre de curso (escala Likert 1–5) | Promedio ≥ 4.0 |
| Percepción de claridad de la metodología teoría–xv6–profesional–simulación | Encuesta de cierre de curso | Promedio ≥ 4.0 |
| Retroalimentación cualitativa sobre Invenio Fest | Encuesta abierta + observación docente | Análisis cualitativo, sin meta numérica |

## 2.4 Periodicidad de Revisión

- Indicadores de resultado y de proceso: al cierre de cada cohorte (cada vez que se imparte el curso).
- Indicadores de satisfacción: al cierre de cada cohorte, vía encuesta estandarizada.
- Revisión consolidada anual: comparación entre cohortes para detectar tendencias (ver Estrategia de Mejora Continua).

# PARTE 3 — Instrumentos para Auditorías Académicas

## 3.1 Checklist de Auditoría de Curso (uso de coordinación académica)

- [ ] El syllabus entregado a estudiantes coincide con el syllabus institucional oficial vigente.
- [ ] El cronograma ejecutado coincide con el cronograma planificado (o las desviaciones están justificadas y documentadas).
- [ ] Las 4 especificaciones de proyecto fueron entregadas a los estudiantes en las semanas correspondientes.
- [ ] Las rúbricas aplicadas corresponden a las rúbricas institucionales vigentes (sin modificaciones no autorizadas).
- [ ] Existe evidencia de Defensa Técnica Individual para el 100% de los estudiantes evaluados.
- [ ] Existe evidencia de participación en Invenio Fest para el 100% de los estudiantes evaluados (o justificación documentada de excepciones).
- [ ] Los Portafolios Técnicos Finales están disponibles y completos para la muestra auditada.
- [ ] Las calificaciones registradas en el sistema institucional son trazables hasta las rúbricas aplicadas (sin discrepancias no explicadas).
- [ ] No se identifica evidencia de que el curso se haya desviado hacia administración de sistemas, DevOps o contenido fuera del alcance declarado en el syllabus.
- [ ] La política de uso de IA fue comunicada explícitamente a los estudiantes y aplicada de forma consistente en la Defensa Técnica.

## 3.2 Formato de Hallazgos de Auditoría

| Campo | Detalle |
|---|---|
| Curso / Sección / Cohorte | |
| Fecha de auditoría | |
| Auditor(a) | |
| Hallazgo | Descripción objetiva |
| Evidencia revisada | Documento(s) específico(s) |
| Severidad | Crítica / Mayor / Menor / Observación |
| Recomendación | Acción correctiva sugerida |
| Responsable de seguimiento | |
| Fecha límite de cierre | |

## 3.3 Niveles de Severidad (criterio sugerido)

| Nivel | Criterio |
|---|---|
| **Crítica** | Compromete la validez de la acreditación (p. ej. ausencia total de evidencia de un componente de evaluación) |
| **Mayor** | Desviación significativa de la planificación sin justificación documentada |
| **Menor** | Inconsistencias administrativas sin impacto en resultados de aprendizaje |
| **Observación** | Oportunidad de mejora sin riesgo actual |

## 3.4 Flujo de Auditoría Recomendado

```
Selección de cohorte/sección a auditar
        ↓
Aplicación del Checklist (3.1)
        ↓
Registro de hallazgos (formato 3.2)
        ↓
Clasificación por severidad (3.3)
        ↓
Plan de acción correctiva (responsable + fecha)
        ↓
Verificación de cierre en la siguiente cohorte
```

Este conjunto de instrumentos se diseñó para integrarse directamente con la **Estrategia de Mejora Continua** y el **Plan de Implementación Docente** (documento final de esta fase), cerrando el ciclo de calidad del curso.
